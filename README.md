# karimabousleiman.com

Personal portfolio of Karim Abousleiman. Live at https://karimabousleiman.com, deployed by Netlify from `main`.

```sh
npm install
npm run dev     # local dev server
npm run build   # production build, must pass before pushing
```

Project notes for contributors and AI agents: `CLAUDE.md` (how the code is organised, hosting, rules, open questions), `PRODUCT.md` (who the site is for) and `DESIGN.md` (visual system).
